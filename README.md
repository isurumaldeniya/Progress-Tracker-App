# Progress-Tracker-App
Daily task progress tracker built with React Native (Expo) and ASP.NET Core, as a hands-on learning project.

This is a React Native (Expo) app that acts as a progress tracker for day-to-day tasks. The backend is written in ASP.NET Core. The project is purely for study: to relearn core coding practices and to do everything myself, using AI as a mentor rather than to write the code.
